# Voicefect

録音した自分の声を、ブラウザ内だけで加工して再生・ダウンロードする完全静的サイトです。

## 機能

- MediaRecorder によるマイク録音
- Web Audio API による録音後の音声加工
- 元音声の再生
- 加工音声の再生
- 低い声 / 高い声 / ロボット風 / エコー / ラジオ風 / 逆再生
- 加工後音声の WAV ダウンロード
- マイク許可エラーの日本語表示
- スマホ向けレスポンシブ UI

## プライバシー

ユーザーの音声は外部送信しません。録音、加工、書き出しはすべてブラウザ内で処理します。

## ローカルで開く方法

HTTPS または localhost での利用を推奨します。ファイルを直接開くより、ローカルサーバーで確認してください。

```bash
python3 -m http.server 8000
```

ブラウザで以下を開きます。

```text
http://localhost:8000/
```

## GitHub Pages で公開する方法

1. この4ファイルを GitHub リポジトリに置きます。
2. GitHub のリポジトリ画面で `Settings` を開きます。
3. `Pages` を開きます。
4. `Build and deployment` の `Source` を `Deploy from a branch` にします。
5. `Branch` で `main` と `/root` を選んで `Save` します。
6. 表示された GitHub Pages の URL を HTTPS で開きます。

## ブラウザ注意点

- Chrome / Edge: MediaRecorder と Web Audio API の対応が安定しています。
- Safari: バージョンや端末により録音形式の対応が異なります。録音できない場合は最新版に更新してください。
- 非対応ブラウザでは、画面に理由を表示して録音ボタンを無効化します。
- マイク録音は HTTPS が前提です。ただし localhost はテスト用に利用できます。

## 音声とダウンロード

加工後音声は可能な限り WAV 形式で書き出します。録音元の内部形式はブラウザにより WebM / MP4 などに変わります。

## 利用時の注意

録音中はハウリング防止のため再生できません。スピーカー音の回り込みを避けるため、イヤホン利用を推奨します。
